# 더비 DERBY — 지역 리그에서 전국 무대까지 (시제품)

> 저장소 이름은 ETS(2020년 원본)를 유지. `logo.svg` = 로고(센터서클을 반으로 나눈 기호: 두 팀이 맞붙는 더비)

아마추어 팀이 **지역 리그**와 **지역 간 경기(전국전)**로 겨루고, 성적에 따라 **사이트 공간을 나눠 갖는** 디시인사이드식 축구 커뮤니티.

`index.html` 한 파일을 브라우저로 열면 바로 동작합니다. 데이터는 그 브라우저에만 저장되고, 상단 **데모 계정**으로 관리자 / 각 팀 주장 / 일반회원을 바꿔 가며 흐름을 볼 수 있습니다.

## 차별점

- 플랩풋볼 등 소셜매치는 "개인이 공 차러 가는 곳", ETS는 "팀이 이름을 알리는 곳"
- 리그 성적 → 사이트 공간이라는 보상 구조
- 경기 결과가 확정되면 갤러리에 결과 글이 자동으로 올라가 리그와 커뮤니티가 연결됨

## 구조

| 단위 | 순위 방식 | 보상 |
|---|---|---|
| 지역 갤러리 (울산·부산·경남 …) | 지역 리그: 경기당 승점 → 득실차 → 다득점 | 1~3위: 그 갤러리 상단 공간 (1위 큰 칸, 2~3위 절반) |
| 전국 | 레이팅(Elo): 지역 리그 + 전국전 모두 반영 | 1~10위: 사이트 메인 공간 (1위 → 7~10위로 갈수록 작은 칸) |

### 결과 신뢰 장치
- 한 팀이 등록하고 **상대 팀 주장이 승인**해야 확정
- 같은 상대와는 시즌 **2경기까지만** 지역 순위에 반영
- 시즌 **3경기 미만** 팀은 순위권 제외
- 지역에 순위권 팀이 **4팀 미만**이면 그 지역 보상은 보류
- 경기 사진 첨부(분쟁 근거)

### 화면
- 홈: 전국 명예의 전당, 지역 갤러리 카드, 전국 레이팅 상위, 전체 개념글, 매치 모집
- 지역 갤러리: 상단 1~3위 공간, 전체글 / 개념글 / 지역 리그(순위표·경기 기록)
- 매치모집: 지역 필터, 경기일·장소·실력, 모집중/마감
- 대회·순위: 결과 등록, 확인 대기, 전국 레이팅 순위, 최근 경기, 시즌 마감(관리자), 지난 시즌
- 팀 페이지: 레이팅·지역 순위·레이팅 추이 그래프·최근 경기·소개·연락처 (공간을 누르면 여기로 이동)
- 우리팀: 배너 이미지·홍보 문구·소개·연락처·링크·모집 여부 편집

## 코드 구조 (`index.html`)

| 구역 | 역할 |
|---|---|
| 1. 데이터 계층 `DB` | 지역·팀·회원·시즌·경기·게시글 저장, 지역 순위·레이팅 계산. **실서비스 전환 시 여기만 교체** |
| 2. 공통 도구 | 글자 이스케이프(XSS 방지), https 링크만 허용, 이미지 축소, 그래프 |
| 3. 화면 | 홈 / 지역 갤러리 / 매치모집 / 글보기·쓰기 / 대회 / 팀 페이지 / 우리팀 / 이용안내 |
| 4. 동작 연결 | 클릭·입력 이벤트 처리 |

규칙 수치(최소 경기 수, 같은 상대 반영 한도, 보상 순위 수 등)는 맨 위 `RULE` 한 곳에서 바꿉니다.

## 실서비스로 가려면 (Firebase + Cloudflare)

- **Firebase Authentication**: 데모 계정 → 실제 로그인(구글·카카오 등)
- **Firestore**: `regions`, `teams`, `users`, `seasons`, `matches`, `posts`(+`comments`)
- **Firebase Storage**: 팀 배너, 경기 사진
- **보안 규칙**: 경기 승인은 상대 팀 주장·관리자만 / 팀 정보는 그 팀 주장·관리자만 / 시즌 확정은 관리자만
- **순위·레이팅 계산**과 자동 결과 글은 서버(Cloud Functions)에서 처리해 조작 방지
- **Cloudflare Workers**: GitHub 브랜치 푸시 시 자동 배포
