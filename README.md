# ETS — 아마추어 축구 갤러리 (v2 시제품)

팀끼리 실제로 경기를 하고, 시즌 성적에 따라 **메인 페이지 공간을 1~10위 팀이 나눠 갖는** 디시인사이드식 축구 커뮤니티.

`index.html` 한 파일을 브라우저로 열면 바로 동작합니다. 지금은 데이터가 그 브라우저에만 저장되는 시제품이고, 화면 상단 **데모 계정**으로 관리자 / 각 팀 주장 / 일반회원을 바꿔 가며 흐름을 볼 수 있습니다.

## 핵심 흐름

1. **매치모집** 게시판에서 상대 팀을 구한다.
2. 경기 후 한 팀 주장이 **대회·순위**에 스코어 등록 → 상대 팀 주장이 **승인**해야 순위표에 반영(일방적 조작 방지).
3. 순위: 승3·무1·패0, 동점 시 득실차 → 다득점.
4. 시즌 종료 시 관리자가 자동 계산된 순위를 확인·조정(몰수·징계 등) 후 **확정** → 다음 시즌 자동 시작.
5. 확정된 1~10위가 메인 **명예의 전당** 공간을 받음.
   | 순위 | 공간 | 홍보문구 |
   |---|---|---|
   | 1위 | 전체 폭 대형 배너 (3:1) | 60자 |
   | 2~3위 | 절반 폭 (2:1) | 40자 |
   | 4~6위 | 1/3 폭 | 30자 |
   | 7~10위 | 1/4 폭 | 20자 |
6. 공간을 받은 팀은 **우리팀 공간**에서 이미지·문구·링크를 직접 수정. 관리자는 부적절한 내용을 내릴 수 있음.

게시판: 자유갤러리(추천/비추천, 추천 10개 이상 = 개념글, 댓글, 검색), 매치모집(경기일·장소·실력, 모집중/마감).

## 코드 구조 (`index.html`)

| 구역 | 역할 |
|---|---|
| 1. 데이터 계층 `DB` | 팀·회원·시즌·경기·공간·게시글 저장과 순위 계산. **실서비스 전환 시 여기만 교체** |
| 2. 공통 도구 | 글자 이스케이프(XSS 방지), https 링크만 허용, 이미지 축소(1200px) |
| 3. 화면 | 홈 / 게시판 / 글보기 / 글쓰기 / 대회·순위 / 우리팀 공간 / 이용안내 |
| 4. 동작 연결 | 클릭·입력 이벤트 처리 |

## 실서비스로 가려면 (Firebase + Cloudflare)

- **Firebase Authentication**: 데모 계정 선택 → 실제 로그인(구글/카카오 등)으로 교체
- **Firestore** 컬렉션: `teams`, `users`, `seasons`, `matches`, `slots`, `posts`(+ `comments` 하위 컬렉션)
- **Firebase Storage**: 팀 배너 이미지 (지금은 브라우저에 data URL로 저장)
- **보안 규칙** 필수 항목
  - 경기 결과 `status`를 `ok`로 바꾸는 건 상대 팀 주장 또는 관리자만
  - `slots` 수정은 해당 팀 주장 또는 관리자만
  - 시즌 확정은 관리자만
- **Cloudflare Workers/Pages**: GitHub 연결 → 브랜치 푸시 시 자동 배포 (작업일지 앱과 동일)
