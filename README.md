# ROOTS 루츠 — 생활축구 공식 리그 커뮤니티 (시제품)

> 이름: grassroots(풀뿌리·생활축구)에서 따온 ROOTS. 영어 "root for"(응원하다)의 뜻도 함께 담음. 지역 게시판은 "울산·부산·경남"처럼 지역 이름 그대로.
> 저장소 이름은 ETS(2020년 원본)를 유지. 브랜드: 대표색 블랙(#111613) + 포인트 잔디 초록(#46B874). 로고: 가로형 = ROOTS + 글자 아래 잔디 바닥(`logo-wordmark-*.svg`), 앱 아이콘 = 잔디 위 정통 축구공(`logo.svg`, 보조 라인형 `logo-icon-line*.svg`). 정리 페이지 `logo.html`

대한축구협회 생활축구 디비전(**K5·K6·K7**) 공식 리그를 시·도별 지역 게시판으로 보여 주고, **시즌 성과에 따라 팀에게 사이트 공간을 주는** 서비스.

`index.html` 한 파일을 브라우저로 열면 바로 동작합니다. 리그 데이터는 예시이고, 상단 **데모 계정**으로 관리자 / 팀 주장 / 일반회원을 바꿔 볼 수 있습니다.

## 원칙

- **공식 리그만** 다룬다. 일정·결과는 협회 공식 기록(JOIN KFA)을 읽기 전용으로 표시, 사용자 입력·수정 없음
- **등급이 다른 리그를 한 줄로 세우지 않는다.** 등급별 정상과 승격팀에게 공간을 준다
- 프로·세미프로(K1~K4)는 대상 아님
- 운영자는 **성과로 받는 팀 공간·순위**를 팔지 않는다. 공간을 딴 팀이 스폰서에게 내주는 것은 허용
- 운영자 수익은 따로: 글 목록 사이 **"광고" 한 줄**(운영 광고). 운영자가 직접 받고 직접 검수

## 구조

| 단위 | 내용 | 보상 |
|---|---|---|
| 전국 무대 (사이트 메인) | 17개 시·도 전체 | 10팀: **K5 정상 1 · K6 정상 2 · K7 승격 7** (시·도당 최대 N팀). 1위 = 홈 실시간 인기글 바로 위 한 칸, 2~3위 = 오른쪽 순위 옆 카드, 4~10위 = 그 아래 목록 한 줄(스폰서 이름·링크). 순위표 팀명 옆 스폰서명 |
| 지역 게시판 (17개 시·도) | 그 지역 K5·K6·K7 리그 + 게시판 | **K5 우승 = 글 목록 바로 위 한 칸**, K6·K7 우승 = 오른쪽 순위 옆 카드 |
| 리그 | K5·K6(시·도), K7(구·군 권역) | 리그 1위 = 우승(K6·K7은 승격) |

- 같은 리그 안: 승점 → 득실차 → 다득점
- 다른 리그끼리 비교할 때만(예: K5 정상 1팀 고르기): 경기당 승점 → 득실차 → 다득점
- 시제품은 17개 시·도 모두 예시 리그(지역당 K5·K6·K7 2권역, 16팀)와 예시 글로 채움. 실서비스는 운영 중 지역만 열고 나머지는 "준비 중"
- 지역 게시판 목록은 디시 갤러리 목록처럼 권역별(수도권·강원·충청·호남·영남·제주) + 최근 방문

## 기능

> **핵심 모드(v6)**: 흰 바탕 · 검은 헤더 · 초록은 포인트만. 홈 = 실시간 인기글 목록. 팀 공간은 오른쪽 순위 옆 카드, 글 목록 사이 "광고" 한 줄은 운영 광고(관리자 화면에서 추가·중지·삭제). 아래 표 중 승부 예측·빅매치·더비 지기·순위 카드·관심 팀·비추천·순위 변동·경기별 자동 글은 코드에 남겨 두고 `FEAT` 플래그로 숨김(자동 글은 라운드 요약만).

| 구분 | 기능 |
|---|---|
| 리그 | 공식 일정·결과·순위(읽기 전용), 우승·승격 표시, 등급별 순위, 전국 무대 배정 기준·현재 예상 |
| 커뮤니티 | 지역 게시판 추천 10개 이상 = 인기글 → 홈 실시간 인기글로 올라감(디시 실베·에펨 포텐 방식), 지역 게시판(말머리: 일반·질문·후기·연습경기·공지), 추천, 인기글, 댓글, 검색 |
| 자동 글 | 결과가 들어오면 결과 글, 라운드 전 일정 글 |
| 경기 페이지 | 양 팀·스코어(또는 일정), 팬 승부 예측(홈승/무/원정승, 결과 후 적중률), 최근 5경기 흐름, 시즌 맞대결, 결과 글 연결 (참고: SofaScore 예측) |
| 순위표 보강 | 지난 라운드 대비 순위 변동 ▲▼, 최근 5경기 승·무·패 (참고: FotMob 폼 가이드, FuPa 라이브 순위) |
| 라운드 요약 글 | 결과가 들어오면 지역 게시판마다 자동 작성: 최다 점수 차, 이변(2계단 이상 아래 팀의 승리), 선두 변화 |
| 순위 카드 | 팀 페이지에서 밴드·카톡용 이미지(1080×1350) 생성. 순위·성적·최근 5경기·다음 경기·스폰서명 (참고: fussball.de 위젯을 한국 메신저 환경에 맞춤) |
| 목표까지 거리 | 팀 페이지·내 팀 카드에 "우승·승격까지 승점 n점 차 · 남은 경기 n", 확정·역전 불가도 표시 (근거: 목표 근접 효과, Kivetz 외 2006) |
| 응원 | 팀 페이지·경기 페이지 원클릭 응원(1인 1일 1회), 누적 수 표시 (근거: 참여 문턱 낮추기, Nielsen 90-9-1) |
| 빅매치 | 직전 순위 기준 1·2위 맞대결 또는 상위 3팀 승점 1점 이내 맞대결 표시 (근거: 라이벌 효과) |
| 게시판 지기 | 지역별 지역 매니저 표시, 지기 글에 배지 (근거: 제3의 장소의 "단골과 주인", Oldenburg) |
| 승리 직후 자랑 | 결과 글에서 이긴 팀 순위 카드 바로 만들기 (근거: 반사된 영광 누리기, Cialdini 1976) |
| 관심 팀 | 팀 페이지에서 ☆ 추가(주장은 자기 팀 자동) → 홈 "내 팀" 카드에 순위·다음 경기·지난 결과 |
| 팀 | 팀 페이지(리그 순위·성적·다음 경기·경기 결과·우승/승격 기록·소개·연락처), 공간 꾸미기(배너·문구·링크) |
| 스폰서 | 공간을 받은 팀이 "우리팀 홍보" 또는 "스폰서 광고"로 사용. 일반 업종은 즉시 게시("스폰서" 표시), 병원·건강식품만 운영자 사전 검수, 금지 업종(도박·성인·대부·불법 의약품)은 선택 불가. 거래는 팀–스폰서 직거래 |
| 신고·책임 | 게시 전 팀의 책임 동의 체크. 팀 페이지에서 공간 내용 신고(1인 1회), 3건 누적 시 자동 숨김. 운영자는 신고된 공간·규제 업종만 확인(기각/내리기), 처리 기록 보관 |
| 관리자 | 운영자 확인 목록(신고·규제 업종 검수·처리 기록), 협회 결과 불러오기(데모), 시즌 마감 확정(배정·기록 자동), 부적절 내용 내리기 |

빠진 것(공식 리그 전환으로 불필요): 결과 직접 등록·상대 승인, 레이팅, 지역 간 친선전, 매치모집 탭(→ 말머리 "연습경기").

다음 단계 후보: 관심 팀 팔로우·경기 알림, 선수 개인 기록(협회 개인정보 협의 필요).

## 코드 구조 (`index.html`)

| 구역 | 역할 |
|---|---|
| 1. 데이터 계층 `DB` | 시·도·리그·팀·경기·시즌·게시글, 순위·배정 계산. **실서비스 전환 시 load/save/syncResults만 교체** |
| 2. 공통 도구 | 이스케이프(XSS 방지), https 링크만 허용, 이미지 축소, 배너 |
| 3. 화면 | 홈 / 지역 게시판 / 글 / 리그·순위 / 팀 / 우리팀 / 이용안내 |
| 4. 동작 연결 | 이벤트 처리 |

배정 수치(K5·K6·K7 칸 수, 시·도 최대 팀 수, 지역 게시판 상단 칸 수)는 맨 위 `RULE`에서 바꿉니다. K7 권역 목록은 협회 데이터 연동 시 `LEAGUES`·`REGIONS`를 교체합니다.

## 실서비스로 가려면

- **협회 데이터 연동**: K5~K7 일정·결과·순위(팀 단위, 선수 개인정보 제외)
- **Firebase**: 로그인(구글·카카오 등), Firestore(게시글·팀 정보), Storage(배너)
- **Cloud Functions**: 결과 수신 → 순위 계산·자동 글 게시
- **Cloudflare Workers**: GitHub 푸시 시 자동 배포

## 울산 시범판 (실제 기록)

- `ulsan.html` — 2025 울산 K5·K6·K7 실제 경기 결과(협회 기록 엑셀)로 만든 시범판. 울산만 열림, 14개 리그 84팀 210경기
- 순위·우승·공간 배정·라운드 요약은 실제 결과로 자동 계산. 일반 글은 예시(실제 팀 이야기는 쓰지 않음)
- 몰수·실격 경기 표시, 쌍방 몰수패는 두 팀 모두 패로 계산. 50대 중장년층리그는 K5~K7이 아니라 제외
- 다시 만들기: `python3 tools/extract_league_xlsx.py 원본.xlsx data/ulsan-2025.json` → `python3 tools/build_pilot.py index.html data/ulsan-2025.json ulsan.html`
